# TekFakka | تك فكة — Design Portfolio

**TekFakka is an Arabic-first design studio from Cairo, Egypt.** We create printable planners, trackers and checklists for the Egyptian household, Arabic typography posters, and original mascot characters. All work is 100% original and produced with our own programmatic design pipeline (Python/PIL generators, Noto Arabic fonts under the SIL Open Font License).
